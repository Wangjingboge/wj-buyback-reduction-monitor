# 版式手册 · 回购与减仓报告

页面是**纯静态单文件**：SVG 由 `build.py` 直接拼字符串，不依赖 Chart.js / D3 / 任何 CDN。换机器、断网都能出图。

---

## 一、页面骨架

```
hero        标题 + 副标（区间 / 月数 / 口径一句话）
kpis        4 张数字卡：累计回购 / 累计减仓 / 覆盖率 / 近 12 个月
lead        3 段导语（结论先行，每段带数字）
图一        三联垂直图（回购柱 → 减仓柱 → 沪深300 折线）
三句话      3 张结论卡（等宽、等高、左侧彩色竖条）
图二        年度对账表（含公开统计偏差 + PASS 标签）
图三        极值月份双榜（回购 TOP5 / 减仓 TOP5）
数据准确性   10 行校验表 + 3 张相关系数卡
footer      口径边界 + 署名
```

## 三、三联图的几何（`build.py` 里 `chart()`）

```
viewBox  1400 × 762
ML,MR    66 / 96            # 左留白放金额刻度，右留白放指数点位
A 区     46 起，高 206       # 回购柱，向上
B 区     A 底 + 58，高 206    # 减仓柱，向上
C 区     B 底 + 56，高 132    # 沪深300 折线
```

- **三区共享 X 轴**，柱宽 `step × 0.60`，`step = 绘图宽 / 月份数`。
- **各区独立 y 轴上限**（回购按 50 的倍数、减仓按 200 的倍数，且都乘 1.12 留余量）。所以三区柱高**不可横向比较**，看形状和拐点，图注里也别暗示可以比。
- 年份分隔：每年首月画一条淡竖线，年份标签 `text-anchor="middle"` 落在那根柱的中心。
- X 轴月份标签只在 **1/4/7/10 月** + 首月出现，格式 `YY.MM`（如 `22.04`）。每月都标会糊成一片。
- 峰值柱顶标数值（11.5px、700 字重），`y = 柱顶 − 8`。

## 四、踩过的坑（重画会重踩）

1. **峰值标签溢出**。最初 `a_ceil = (int(max/50)+1)*50`，262 亿的柱子直接顶到 300 的格线，标签压在线外。改成 `max*1.12` 再取整后有余量。
2. **标签放进柱内会消失**。柱子宽约 12px，三位数字放进去白字落白底，肉眼看不见。**永远放柱顶上方**。
3. **结论卡塞两张进一个 div**。`grid-template-columns:repeat(3,1fr)` 下只有 2 个子元素，第三列空着、第一张卡被拉得极高。一张卡只放一张卡的内容。
4. **`align-items:start` 让三卡参差**。改成 `stretch`（默认），边框等高等宽，底部留白比参差好看。
5. **中文断词**。`14,970 亿元` 会被拆成 `14,970 亿 / 元。`，`<b>` 上要加 `white-space:nowrap`。
6. **X 轴标签太密**。60 个月全标 → 糊。按季度标。
7. **相关系数卡写成 `±{{C_BUY}}`**。占位符语义错，会被替换成相关系数。三张卡分别是：回购相关、减仓相关、样本完整性。
8. **表格里 2021 只有 2 个月**。必须标「不完整」，否则读者会拿 1,789 亿当 2021 全年减仓额。

## 六、长图导出

```bash
node scripts/export_long.js <html> <png> 1180 2360
```

- 视口 1180 正好等于页面 `max-width`，不会触发 `@media (max-width:880px)` 的移动端塌陷。
- 2x 像素 → 约 2360 × 7700。
- 脚本会注入一段去外框的样式，并自动找 playwright-core 与 Chrome/Edge；找不到会给出可照做的报错，**不要写死本机路径**。
